# 星継ぎのエテルナ（Hoshitsugi no Eterna）

消えゆく星を継ぐ、**スマホで遊べる王道ターン制RPG**。
外部アセットやビルド工程は一切なく、素のブラウザだけで動作し、PWA としてオフラインでも遊べます。

> ⚠️ 既存の「スタックタワー」（リポジトリ直下）には手を加えていません。本作は `rpg/` 以下に完全自己完結で追加しています。

## 遊び方

### 起動
- ブラウザで **`rpg/index.html`** を開くだけ（ローカルサーバ推奨: `cd rpg && python3 -m http.server` → `http://localhost:8000/`）。
- スマホでは「ホーム画面に追加」でフルスクリーンの PWA として遊べます。

### 操作（縦画面・タッチ最適化）
| 操作 | タッチ | キーボード |
| --- | --- | --- |
| 移動 | 画面左下の十字キー | 矢印 / WASD |
| 調べる・話す・決定 | 右下の ● ボタン | Enter / Space / Z |
| メニュー | 右下の ≡ ボタン | Esc / M |
| 戦闘コマンド | メニューをタップ | 矢印＋Enter |

### 進行
星守村 → 囁きの森 → 古の遺跡（守番戦・星導の鍵）→ 星の尖塔（星喰いノクス戦）→ エンディング。
- 村の**星の泉**（水辺のきらめき）を調べると HP/MP が全回復します。
- 村の**どうぐ屋**でやくそう等を購入。マップ移動ごとに**オートセーブ**、メニューから手動セーブも可能。

## 物語
世界の灯〈天の星〉が消えかけ、影の魔物が湧く時代。星守の血を継ぐ少年**リオ**が、
魔法使い**セナ**、元騎士**ガード**と共に、かつて父が果たせなかった旅——星を継ぐ旅——へ出る。
リオの父の伏線、各キャラクターの声、進行に応じて変化する村人たちの言葉など、王道ジュブナイルとして描いています。

## 特徴
- **戦闘**: ターン制コマンド（たたかう／とくぎ／どうぐ／ぼうぎょ／にげる）。属性の弱点・耐性、会心、状況判断する敵AI、HPフェーズで戦い方を変えるボス、撃破・被弾・回復の演出。
- **グラフィック**: canvas 2D による手続き的ピクセルアート。地形・キャラ・敵・ボス・戦闘背景・パーティクルまですべてコード生成（オフライン動作）。
- **サウンド**: WebAudio による効果音とテーマ別BGM（外部音源なし・ミュート可）。
- **PWA**: manifest とサービスワーカーでオフライン対応。

## プロジェクト構成
```
rpg/
├── index.html            エントリ
├── manifest.webmanifest  PWA マニフェスト
├── service-worker.js     オフラインキャッシュ
├── icon-192.svg / 512    アイコン
├── css/style.css         UI スタイル
└── js/
    ├── data.js    ゲームデータ（スキル/アイテム/敵/仲間/マップ）＝契約の中核
    ├── story.js   物語・会話スクリプト・進行フラグ
    ├── gfx.js     手続き的描画エンジン
    ├── audio.js   WebAudio 効果音・BGM
    ├── ui.js      DOM UI（会話窓・メニュー・戦闘HUD・ショップ・仮想パッド）
    ├── battle.js  ターン制バトル
    ├── world.js   探索（移動・当たり判定・イベント・エンカウント・遷移）
    └── engine.js  中枢（状態・成長・セーブ・シーン管理・ループ）
```

## 制作体制（指揮系統を分けたチーム制作）
総合ディレクターがアーキテクチャ・データ契約・統合・QA を統括し、担当ファイルを分離した専門リードが並行制作しました。
- **総合ディレクター**: 設計、データ契約、探索エンジン(world)・中枢(engine)・UI、統合、品質保証（自動テスト・実機検証・不具合修正）
- **グラフィックリード**: `gfx.js` / `css/style.css`（描画とUI意匠）
- **シナリオリード**: `story.js`（物語・会話・伏線）
- **バトルリード**: `battle.js`（戦闘のAI・バランス・演出・不具合修正）

公開APIの契約を固定して各リードが担当ファイルのみを編集し、ディレクターが統合後に自動テスト（構文・データ整合性・ヘッドレスChromiumでの通しプレイ・物語進行チェーン）で検証・修正しています。
